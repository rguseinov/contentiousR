# The period in which each leader took office

The period in which each leader took office

## Usage

``` r
leader_start_period(leader, unit)
```

## Arguments

- leader:

  Rows of
  [`leader_spells()`](https://rguseinov.github.io/contentiousR/dev/reference/leader_spells.md).

- unit:

  `"quarter"`, `"month"`, or `"day"`.

## Value

A data frame with the time keys of `unit`.
