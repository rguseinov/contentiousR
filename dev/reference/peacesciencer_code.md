# peacesciencer's country code for a contentiousR panel

peacesciencer's country code for a contentiousR panel

## Usage

``` r
peacesciencer_code(panel, coding_system)
```

## Arguments

- panel:

  A country-year panel.

- coding_system:

  `"cow"` or `"gw"`.

## Value

The `ccode` (standard COW: 260 for West Germany in 1955-1989, 315 for
Czechoslovakia up to 1992) or `gwcode` (equal to `gw`) values.
