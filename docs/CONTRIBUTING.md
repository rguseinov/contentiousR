# Contributing to contentiousR

Bug reports and focused pull requests are welcome through the [GitHub
repository](https://github.com/rguseinov/contentiousR).

For code changes:

1.  Add or update a test that demonstrates the intended behavior.
2.  Run
    [`devtools::document()`](https://devtools.r-lib.org/reference/document.html)
    and
    [`devtools::test()`](https://devtools.r-lib.org/reference/test.html).
3.  Run
    [`devtools::check()`](https://devtools.r-lib.org/reference/check.html)
    before opening a pull request.
4.  Describe any change to source-data interpretation or statistical
    behavior explicitly in the pull request and in `NEWS.md`.

Do not add third-party data files without recording their source,
version, citation, and redistribution terms.
