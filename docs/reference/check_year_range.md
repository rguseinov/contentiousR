# Check year range

Check year range

## Usage

``` r
check_year_range(start_year, end_year, min_year = NULL, max_year = NULL)
```

## Arguments

- start_year:

  First year.

- end_year:

  Last year.

- min_year:

  Optional. If given, `start_year` must be at least this.

- max_year:

  Optional. If given, `end_year` must be at most this.
