# Contributing to contentiousR

Bug reports and focused pull requests are welcome through the
[GitHub repository](https://github.com/rguseinov/contentiousR).

For code changes:

1. Add or update a test that demonstrates the intended behavior.
2. Run `devtools::document()` and `devtools::test()`.
3. Run `devtools::check()` before opening a pull request.
4. Describe any change to source-data interpretation or statistical behavior
   explicitly in the pull request and in `NEWS.md`.

Do not add third-party data files without recording their source, version,
citation, and redistribution terms.
