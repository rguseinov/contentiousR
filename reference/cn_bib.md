# Bundled bibliography for cn_cite()

A `bibentry` object with one entry per bundled or interoperable data
source, used by
[`cn_cite()`](https://rguseinov.github.io/contentiousR/reference/cn_cite.md).
Each entry's `keywords` field lists the `contentiousR` function(s)
and/or `dataset =` value(s) it documents.

## Usage

``` r
cn_bib
```

## Format

A `bibentry` object of length 22.

## Source

`data-raw/contentiousR_bib.bib` and `data-raw/contentiousR_bib.R`.
