# Detect coding system from a panel data frame

Detect coding system from a panel data frame

## Usage

``` r
detect_coding_system(panel)
```

## Arguments

- panel:

  A data frame produced by
  [`build_states_panel()`](https://rguseinov.github.io/contentiousR/reference/build_states_panel.md).

## Value

`"cow"` or `"gw"`.
